# web
Bir Tebessüm Bin Mutluluk Derneği

Bu depo, dernek için temel alanları içeren basit bir tanıtım sayfası içerir:
- Üye yönetimi
- Gönüllü yönetimi
- Yönetim
- Genel kurul
- Faaliyetler
- Dernek başarısı için gerekli temel özellikler

Sayfayı görüntülemek için `index.html` dosyasını bir tarayıcıda açabilirsiniz.
